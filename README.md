# QuantStat

QuantStat is a web-based quantitative market analytics and statistical analysis platform.

## Planned architecture

- React frontend
- ASP.NET Core Web API
- Shared .NET domain and calculation layer
- Provider-independent market data architecture
- Statistical and quantitative analysis
- Automated tests

The existing EthStatistics desktop application will be used as the reference implementation while QuantStat is developed independently.

## Planned functionality

- Multi-asset market data
- Interactive price charts
- Descriptive statistics
- Statistical estimators
- Market returns
- Volatility analysis
- RSI and technical indicators
- Probability distributions
- Confidence intervals
- Hypothesis testing
- Data import
- Forecasting
- Statistical reference/dictionary
- User settings
- Microsoft authentication
